author-grouped messages — 4 options

Same #archlinux snippet, four ways to collapse consecutive same-author lines. Grouping rule for all: same nick, within ~5 min, uninterrupted by a system line or another author. All built on the terminal base — swappable into any of the other styles.

A · Nick-once column ditto / IRCCloud-ish

Keep the fixed ts | nick | msg grid. First line of a run shows the nick; repeats blank it out. Timestamp stays on every line. Most IRC-faithful, scannable nick column. Repeated nicks leave whitespace.

B · Stacked header block Slack / Discord

Author + time on their own line, messages indented underneath. Most vertical breathing room. Cleanest for chatty bursts, easy to add avatars later. Loses the aligned nick column; per-line timestamps gone (hover to reveal).

A vertical bar in the author's nick color spans the whole group, header on top. Strong visual author separation, color does double duty, scales to bubbles. Eats a few px of width; rail color must track the nick palette.

D · Classic <nick> + ditto minimal, pure IRC

Keep the literal <nick> bracket style. Repeats collapse to a dim ” ditto so the run reads as one speaker. Densest option, zero layout change. Feels exactly like a real client log. Subtlest grouping — easy to miss.
